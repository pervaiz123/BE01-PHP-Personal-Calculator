# BE01 - PHP Personal Information and Calculator

A beginner-level PHP application demonstrating PHP fundamentals and server-side programming.

## Features
- Dynamic personal information display
- PHP variables, constants and data types
- Addition, subtraction, multiplication and division
- Division-by-zero validation
- Server-side form processing using POST
- Input validation and type conversion
- PHP debugging using var_dump and print_r

## Requirements
- PHP 8.4 or compatible PHP version

## Run the application
Open CMD in the project directory and execute:

php -S localhost:8000

Open http://localhost:8000 in your browser.
